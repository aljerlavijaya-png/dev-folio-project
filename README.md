# Responsive Dev-Folio Landing Page

A responsive personal portfolio website developed as a Minor Internship Project.

## Project Description

This project is a single-page professional Dev-Folio website created using HTML, CSS, Bootstrap and JavaScript.

The website is designed to work on mobile, tablet and desktop screens.

## Features

- Responsive Bootstrap Navbar
- Hero section
- About section
- Skills section
- Six skill cards
- Contact form
- JavaScript form validation
- Error messages for invalid input
- Success message for valid form submission
- Responsive design
- Hover effects
- Social media links

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git
- GitHub

## Skills Included

1. Java
2. HTML
3. CSS
4. JavaScript
5. Python
6. React

## Form Validation

The contact form validates:

- Name must not be empty
- Email must not be empty
- Email must have a valid format
- Message must contain at least 10 characters
